---

## 🧑‍💼 Team Leader (Líder d’Equip)

Responsable de:

- coordinar el grup,
- revisar canvis,
- validar Pull Requests,
- integrar contribucions.

---

## 👨‍💻 Membres de l’equip

Responsables de:

- desenvolupar tasques,
- treballar sobre branques pròpies,
- crear commits,
- enviar Pull Requests.
