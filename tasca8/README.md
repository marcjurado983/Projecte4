# 🛡️ T08 — Auditoria de Qualitat i Estandardització de Servidors

## 👤 Tasca individual

---

# 📖 Introducció

Benvinguts, equip.

Durant les darreres setmanes heu implementat serveis avançats per als clients:

- 📂 servidors de fitxers (**NFS**),
- 🖨️ serveis d’impressió (**CUPS**),
- 👥 autenticació centralitzada (**LDAP**),
- i altres serveis d’infraestructura.

Però hi ha una realitat molt important:

> Cap servei avançat és fiable si la base del sistema operatiu és deficient.

---

# ⚠️ El problema

Un servidor amb:

- configuració de xarxa incorrecta,
- permisos mal assignats,
- paquets desactualitzats,
- serveis innecessaris actius,
- o males pràctiques de configuració,

es converteix en:

- 🔓 un risc de seguretat,
- 🧨 una futura incidència,
- 📉 una mala experiència per al client.

A **EverPia**, la nostra reputació depèn de la:

- robustesa,
- estabilitat,
- seguretat,
- i qualitat dels desplegaments.

---

# 🎯 La vostra missió

## Auditoria i Estandardització del Servidor Base

Abans de desplegar nous serveis avançats, consolidarem la base del sistema.

Aquesta activitat simula:

- una auditoria interna,
- i l’aplicació del nostre protocol corporatiu de desplegament.

---

# 📋 SOP — Standard Operating Procedure

Treballareu seguint el nostre:

## 🏗️ Protocol de Desplegament Estàndard (SOP)

L’objectiu és demostrar que sou capaços de:

- desplegar una màquina virtual nova,
- configurar correctament Ubuntu Server,
- aplicar bones pràctiques,
- validar la configuració base,
- i deixar el sistema preparat per producció.
